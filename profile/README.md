:wave: Welcome to the official GitHub organization of Project Konfidence, a comprehensive software delivery framework for microservice-based SaaS applications.

## :bulb: What is Konfidence?

Konfidence is a framework aimed at simplifying and enhancing the delivery of microservice-based SaaS applications. It addresses shortcomings of traditional CI/CD pipelines, ensuring reproducible deployments and mitigating the risk of inconsistent delivery or untested features reaching production. At its core, it uses deployment vectors, which are immutable sets of versioned software artifacts, to ensure reliable and consistent operations. Konfidence facilitates smooth, daily software releases and reduces infrastructure complexity, allowing developers to focus on business logic rather than tool management.

## :handshake: Konfidence and ApeiroRA

Konfidence is part of the Apeiro Reference Architecture (ApeiroRA), which is an Important Project of Common European Interest - Next Generation Cloud Infrastructures and Services (IPCEI-CIS). Konfidence offers enterprises an integrated service toolchain that supports modern deployment strategies such as ring deployments and feature toggle management and defines a clear, repeatable delivery process based on CNCF best practices.
